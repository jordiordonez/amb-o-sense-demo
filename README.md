# Amb o sense · prototip

Prototip de **Solucions Digitals JOA** d'una eina ciutadana per comparar els escenaris amb i
sense Acord d'associació Andorra–UE. **No és un servei oficial del Govern d'Andorra.** Els
continguts són una proposta pendent de validació.

- Web estàtica: HTML, CSS i JavaScript, sense dependències ni recursos externs.
- No recull cap dada: sense galetes, analítica ni emmagatzematge. Tot es calcula al navegador.
- Els PDF de `textos/` són la versió catalana de l'Acord aprovada pel Consell de la UE,
  publicada a andorraue.ad (traducció no oficial fins a la signatura).

Publicació: GitHub Pages, branca `main`, carpeta arrel.
